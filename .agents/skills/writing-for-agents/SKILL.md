---
name: writing-for-agents
description: Write or revise instructions that agents consume, including skills, AGENTS.md, CLAUDE.md, and linked agent documentation.
---

Write for reliable execution.

* State clearly when the document applies.
* Put the main workflow in clear steps with observable completion criteria.
* Keep common-path instructions local; move branch-specific or bulky reference behind pointers.
* Keep each rule in one authoritative place. Do not restate facts the agent can cheaply inspect from the environment.
* Remove instructions that are redundant, stale, obvious from context, or unlikely to change model behavior.
* Prefer concrete actions and familiar concepts over explanation or invented terminology.
